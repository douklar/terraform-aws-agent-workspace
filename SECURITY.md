# Security Policy

## Supported Versions

Only the current `main` branch is supported.

## Reporting a Vulnerability

If you find a security issue, please do not open a public issue with exploit details.

Preferred reporting options:

1. Use GitHub's private vulnerability reporting or repository security advisory flow when available.
2. If private reporting is not enabled, contact the repository maintainers through the public profile contact listed for the project without publishing exploit details.
3. Include a clear summary, impact, and reproduction steps if safe to share privately.

## What to Include

- Affected file or resource
- Impacted AWS service or Terraform resource
- Reproduction steps or proof of concept
- Any suggested mitigation

I will review reports as quickly as possible and coordinate a fix.
